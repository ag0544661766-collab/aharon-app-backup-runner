Privacy policy - Aharon app backup runner

Last updated: October 1, 2026.

This app is a private Google Apps Script used only by its owner. No one else is asked to authorize it.

Google data the app can access

  • Cloud Datastore (Firestore) data in the owner's Google Cloud projects. The authorization is broad, but the script currently reads only one project's data.
  • Google Drive files and folders that the app itself creates (drive.file), used to store backup copies.
  • External requests and scheduled triggers, so it can run automatically.

How it is used

The script reads data and writes backup copies only to a private folder in the owner's Google Drive. It does not publicly share or sell this data, and it does not use it for advertising. The owner may open or download the backup files to check or restore them.

Retention

Backups stay in the owner's Drive until the owner deletes them. Access can be revoked at myaccount.google.com/permissions.
